# keryon-updates

Canal de distribución de actualizaciones de **Keryon** (panel de gestión para farmacias).

Este repositorio solo aloja los paquetes `.zip` ya compilados de cada versión, publicados como [Releases](../../releases) — no contiene código fuente. Cada instalación de Keryon comprueba aquí si hay una versión más reciente y, si el administrador lo confirma, la descarga desde aquí.

El código fuente vive en un repositorio privado aparte.
